# DiToVR プライバシーポリシー

最終更新: 2026年10月24日

DiToVR は、利用者が承認した Discord の通知を、同じ PC の XSOverlay に転送する Windows アプリです。

## 使用する情報

Discord の認証情報、利用者・チャンネル・サーバーの ID、通知の送信者名・本文・アイコン、チャンネル名・サーバー名を、接続、通知表示、許可リストの判定に使用します。任意の自動判別 Bot を設定した場合は、指定した利用者の状態を受信対象の切り替えに使用します。利用者自身の Client ID 等で認証し、Discord アカウントのパスワードやアカウントトークンは入力しません。

## 保存と送信

設定は Windows のユーザープロファイル内に保存します。Client Secret、OAuth トークン、Bot Token は Windows DPAPI で暗号化します。接続に必要な情報は Discord の公式サービスへ送り、アイコンは Discord の公式 CDN から取得します。通知は PC 上の XSOverlay に送ります。これらのサービス自体の処理には各提供元の規約とプライバシーポリシーが適用されます。

開発者のサーバーに会話・認証情報・利用状況を収集する機能、広告、解析・追跡機能はありません。開発に生成 AI を使用していますが、アプリに生成 AI 機能は組み込まれておらず、会話を生成 AI に送信しません。

Store 版の配信・更新は Microsoft Store が管理します。GitHub 版は GitHub の固定配布先に更新を確認しますが、Discord の会話・認証情報は含めません。各サービスには通常の通信で IP アドレス等が伝わります。

本文のコンソールログは初期設定で無効です。利用者が有効にした場合は通知情報がコンソールに出力されます。受信診断は本文・ID を含まない日時・件数・結果を起動中のメモリに保持し、終了時に破棄します。

## 管理と削除

配信用表示で、その後に送信する名前・本文・アイコンを隠せます。すでに表示・送信した通知は消せません。設定画面で接続情報・Bot Token を変更・削除でき、Discord 側で認可を取り消すこともできます。

終了後に設定フォルダーを削除すると設定・認証情報を削除できます。GitHub 版のアンインストールでは設定削除を選択できます。Store 版のデータは Windows のアプリ管理に従って削除されます。別途バックアップした設定や旧版の設定は利用者自身で管理してください。
