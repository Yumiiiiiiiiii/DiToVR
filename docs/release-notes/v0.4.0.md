- アプリを Rust のネイティブ画面に作り直しました。Microsoft Edge WebView2 は不要になり、起動と待機時の負荷が軽くなります。
- 通知・接続・動作設定・診断を小さなウィンドウで切り替えられます。黒とライトのテーマ、控えめな動き（OS のアニメーション設定にも従います）に対応しました。
- 許可リストは、チャンネル ID または Discord のメッセージリンクを追加し、一覧から個別に削除できます。
- 既存の設定・認証情報・自動更新の設定はそのまま引き継ぎます。通常版は従来どおり署名付きの自動更新に対応し、Microsoft Store 版は Store が更新します。
